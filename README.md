# Ποδοσφαιράκι — Εργαστήριο Φυσικής

Ζωντανή σελίδα: **https://matrix-research-ai.github.io/podosfairaki/**

Εκπαιδευτικό project για το μάθημα «Ερευνητική Εργασία στην Τεχνολογία» (Ε.Ε.Τ. ΕΠΑΛ),
Μάθημα 2ο — *Βιβλιογραφική Έρευνα & Benchmark*. Ένα πραγματικό ποδοσφαιράκι γίνεται
εργαστήριο φυσικής: μετρήσεις σε μονάδες SI, έλεγχος ισχυρισμών και σύγκριση
προσομοίωσης με αναλυτικό μοντέλο.

## Δομή

| Διαδρομή | Περιεχόμενο |
|---|---|
| `index.html` | Αρχική σελίδα / κόμβος του project |
| `simulations/benchmark/` | Ο 3D προσομοιωτής (αυτόνομο HTML, Three.js ενσωματωμένο) |
| `lesson/` | Διαφάνειες Μαθήματος 2ου |
| `handouts/` | Φυλλάδια εργασίας ομάδων |

Όλα τα αρχεία είναι **αυτόνομα HTML** — ανοίγουν από `file://`, USB ή σχολικό δίκτυο
χωρίς internet (μόνο οι γραμματοσειρές είναι προαιρετικές από Google Fonts).

## Ο προσομοιωτής

- **8 επιφάνειες**: MDF, laminate, γυαλί, τσόχα, βερνικωμένο ξύλο, αλουμίνιο, λάστιχο, χαρτόνι.
- **5 μπάλες**: φελλός, πινγκ-πονγκ, πλαστική, ξύλινη, αφρώδης.
- **3 στηρίξεις ράβδου**: απλή τρύπα, ορειχάλκινος δακτύλιος, ρουλεμάν.
- **Πειράματα**
  - 10 ίδια σουτ — επαναληψιμότητα εκτοξευτή (±2 %).
  - Δοκιμή τοιχώματος **5 ↔ 12 cm** με ίδιο σουτ· καταγράφει το ύψος στο τοίχωμα και
    ελέγχει τον ισχυρισμό του φόρουμ.
  - Benchmark **8 επιφανειών** με αναλυτική πρόβλεψη ολίσθησης→κύλισης
    `s = (v₀²−v_r²)/(2μ_k g) + v_r²/(2μ_r g)`, `v_r = v₀/(1+k)`.
  - Σύγκριση **5 μπαλών** στην ίδια επιφάνεια.
- **📚 Πηγές & παραδοχές** μέσα στην εφαρμογή: τιμή μοντέλου, ενδεικτικό βιβλιογραφικό
  εύρος και κατάσταση (σταθερό / πρότυπο / εκτίμηση / παραδοχή) για κάθε παράμετρο.
- Εξαγωγή μετρήσεων **CSV**, λήψη εικόνας PNG, αργή κίνηση, πλήρης οθόνη.

Η προσομοίωση είναι **ενδεικτική**: οι συντελεστές είναι παράμετροι μοντέλου και πρέπει
να επιβεβαιωθούν με πηγές στο Φυλλάδιο 1. Σύγκρινε **τάσεις**, όχι απόλυτα νούμερα.

## Τοπική λειτουργία

Άνοιξε το `index.html` σε browser. Για σερβίρισμα:

```bash
python -m http.server 8000
# http://localhost:8000/
```

## Επαλήθευση

Ο προσομοιωτής ελέγχθηκε σε headless Chrome (WebGL, χωρίς console errors) και offline
(χωρίς δίκτυο). Το benchmark 8 επιφανειών συμφωνεί με την αναλυτική πρόβλεψη εντός
±4 % σε όλες τις περιπτώσεις.
